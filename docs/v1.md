# Implementation Plan - Functional Rebuild of OmniConvert Engine & Web UI

Rebuild **OmniConvert** completely from scratch as a 100% self-hosted, offline-capable universal file converter web application. Focus on real, robust end-to-end functionality (no external paid API dependencies like ConvertAPI), robust error handling, edge-case coverage, and a fully functional user-facing web interface.

## User Review Required

> [!IMPORTANT]
> **Key Architecture Decisions**:
> 1. **100% Local Processing Engine**: Eliminates external API dependencies (such as ConvertAPI). All transformations run locally in Python using established open-source libraries (`Pillow`, `pandas`, `openpyxl`, `python-docx`, `pypdf`, `reportlab`, `pyyaml`, `gTTS`, `markdown`, `zipfile`).
> 2. **Functionality First Focus**:
>    - Primary focus on reliable format transformations, input sanitization, error messages, and binary streaming.
>    - UI layout will be clean, simple, and functional (drag & drop, format pills, conversion options, download buttons, error alerts), reserving visual redesigns for a later phase.
> 3. **End-to-End User Verification**:
>    - Backend unit tests (`test_converters.py`) will test *real file conversions* with actual generated sample files (PNG, JPG, PDF, DOCX, XLSX, JSON, CSV, YAML, IPYNB, WAV, MP3, ZIP).
>    - Live FastAPI server (`server.py`) will be tested via browser/HTTP multipart requests to ensure downloads and frontend-backend interactions work seamlessly.

### Backend Converters (`converters/`)

#### [NEW] [converters/image_converter.py](file:///d:/Armaan/Essential%20tool/converters/image_converter.py)
- Support conversions between `PNG`, `JPG`/`JPEG`, `WEBP`, `GIF`, `BMP`, `ICO`, and `TIFF`.
- Support options: `quality` (1-100), `grayscale` (boolean), and `resize` (`width`x`height` or percentage).
- Proper color space handling (e.g., converting RGBA $\rightarrow$ RGB when saving as JPEG).

#### [NEW] [converters/doc_converter.py](file:///d:/Armaan/Essential%20tool/converters/doc_converter.py)
- Support conversions across `PDF`, `DOCX`, `TXT`, `MD`, `HTML`, `XLSX`, `CSV`, `TSV`, and Jupyter Notebooks (`.ipynb`).
- PDF generation using `ReportLab` (for text/markdown/HTML $\rightarrow$ PDF).
- Document parsing & generation using `pypdf` (PDF extraction $\rightarrow$ TXT), `python-docx` (Word generation/parsing), and `pandas` (Excel XLSX $\leftrightarrow$ CSV/TSV/HTML).
- Jupyter Notebook parsing (`.ipynb` JSON extraction $\rightarrow$ Python script, Markdown, HTML, or PDF).

#### [NEW] [converters/data_converter.py](file:///d:/Armaan/Essential%20tool/converters/data_converter.py)
- Support structured data transformations between `JSON`, `YAML`, `XML`, `CSV`, `TSV`, `SQL INSERT` queries, and `Base64`.
- Handle tabular conversions safely using `pandas` and `pyyaml`.
- Custom SQL generator converting JSON/CSV array of objects into structured `INSERT INTO <table> (...) VALUES (...)` statements.

#### [NEW] [converters/audio_converter.py](file:///d:/Armaan/Essential%20tool/converters/audio_converter.py)
- Support Text-to-Speech (TTS) using `gTTS` (`TXT`, `MD`, `HTML` text $\rightarrow$ `MP3` / `WAV` audio stream).
- Support synthetic tone generator for testing audio transformations.

#### [NEW] [converters/archive_converter.py](file:///d:/Armaan/Essential%20tool/converters/archive_converter.py)
- Compress any file into `ZIP` or `TAR.GZ` archives.
- Support extraction of `ZIP` archives into single files or combined format extracts.

#### [NEW] [converters/registry.py](file:///d:/Armaan/Essential%20tool/converters/registry.py)
- Maintain `FORMAT_CATALOG` mapping source extensions to supported target extensions.
- Central `process_conversion()` dispatcher routing incoming byte streams to the appropriate converter handler.
- Comprehensive MIME type mapping and filename extension sanitization.

### FastAPI Server (`server.py`)

#### [NEW] [server.py](file:///d:/Armaan/Essential%20tool/server.py)
- Mount FastAPI app with CORS middleware, static file mounting (`/static`), and custom exception handlers.
- Endpoints:
  - `GET /api/health`: Health status & supported engines list.
  - `GET /api/formats`: Query allowed target formats for a given source extension.
  - `POST /api/convert`: Multipart upload endpoint processing `file`, `target_format`, and `options`. Returns `StreamingResponse` attachment with proper `Content-Disposition` headers.
  - Catch-all `/404` & error fallback handlers.
